# herdr-tunr

[English](README.en.md) ｜ 繁體中文

給 [herdr App](https://herdr.dev) 的小小懸浮播放器：影片在角落轉成 ASCII 畫面，一邊工作一邊看、一邊聽。

herdr 是牧人，[tendr](https://github.com/ailazytech/tendr) 顧爐火，[ranchr](https://github.com/ailazytech/herdr-ranchr) 管整座牧場，tunr 是調頻器。

- **小視窗**：預設 48×16 字，可以切中（64×22）、大（80×27）；拖得動，記得位置，App 重開後還在原處
- **黑白或低彩度**：低彩度只用 8 種壓低飽和度的顏色，不搶工作畫面的注意力
- **可關畫面**：只留聲音，縮小成兩列精簡面板，畫面也不再重畫
- **系統音訊頻譜**：按 📻 顯示電腦正在播的聲音（Spotify、瀏覽器等）的即時跳動 ASCII 頻譜
- **來源**：本機影音檔、直連網址（mp4、mp3…）、YouTube 等 yt-dlp 支援的網址，或電腦系統音訊；拖檔案、按 🔗 輸入網址，或按 📻 切換系統音訊

## 需要

- herdr App（裝好並開過一次）、Node.js 18 以上
- `ffmpeg`、`ffplay`、`ffprobe` 在 PATH 上；播放 YouTube 等網站需要 `yt-dlp`

## 安裝

```bash
git clone https://github.com/ailazytech/herdr-tunr
node herdr-tunr/install.mjs
```

只會裝 `~/.config/herdr-app/mods/tunr/`，不改任何 layout；你的 `config.json` 不會被覆蓋。更新：`git pull` 後再跑一次。
安裝程式會檢查工具並提供安裝指令；互動終端可選擇立即安裝，`--yes` 會自動執行可自動安裝的指令。Linux 的 sudo 指令需手動執行。安裝後新終端才會讀到更新的 PATH；herdr 的新終端會自動更新，不用重開 App。

## 開啟

- 有裝 [herdr-quota](https://github.com/ailazytech/herdr-quota) 的話，底部狀態列有一顆 **tunr** 按鈕，點一下開、再點一下關
- 指令：`herdr-app do mod.open --name tunr`（再一次會關掉）
- 想要快捷鍵：在 `keys.json` 的 `global` 加 `"ctrl-alt-t": "mod.open:tunr"`

## 操作

視窗頂端的標題列：左側顯示來源名稱（系統音訊模式顯示「歌名 — 演出者」；有畫面放不下等提示或錯誤時會暫時取代標題；標題太長被截成「…」時，滑鼠停在上面會顯示完整文字），右側為縮小、放大與關閉視窗按鈕；拖曳標題列空白處或視窗空白背景即可移動位置。
視窗下方的控制列：第一列為播放／暫停、上一首／下一首（依來源切換；📻 模式隱藏或依工作階段顯示）、進度條（可點擊或拖曳跳轉）與時間；第二列左側為播放速度（`1×` 固定寬度文字鈕，支援 `0.75×`、`1×`、`1.25×`、`1.5×`、`2×`，左鍵切下一檔、右鍵往回，非 `1×` 會亮起，📻 系統音訊模式隱藏），右側依序為系統音訊（可來回切換電腦的聲音與原本來源）、輸入網址、畫面開關、黑白／低彩度切換、音量按鈕（滑鼠提示顯示目前音量，點開彈出 0%–100% 滑桿、每格 5%，與網址輸入、透明度滑桿三者互斥，📻 模式隱藏），以及背景透明度按鈕（點開可拖曳滑桿調整 5%–100%，只透明化背景、文字與圖示維持清晰）。
關閉畫面進入「只聽聲音」後會縮小成約 64px 高的兩列精簡模式（尺寸與模式順序為 `只聽聲音 < S < M < L`）：背景會顯示半透明的即時等化器長條（無論是 📻 系統音訊或 tunr 自己播放的檔案／網址皆有，依黑白／低彩與主題配色，暫停時長條會慢慢落下，可用第二列的等化器鈕或 `tunr.eq` 指令開關，會記住）；第一列在標題列右側放得下時顯示時間、第二列改為單排圖示列（保留播放、上一首／下一首、倍速鈕，並將音量按鈕放在等化器與透明度鈕之間，省去黑白／低彩切換），兩列之間有一條細進度線（系統音訊模式不顯示）；開啟輸入網址、音量滑桿或透明度滑桿時會就地取代第二列圖示列並提供確定按鈕（`✓`）。從 `S` 縮小可切入只聽聲音並保留原本寬度，從只聽聲音放大會開回該寬度的畫面（若目前位置放不下畫面，會在第一列暫時顯示提示）。
tunr 自己播放的來源（🔗 網址或拖入的本機檔案）支援**上一首／下一首**與**播完自動接續**：拖入本機影音檔時，會列出同一層資料夾的影音檔並以自然排序（例如 `a2` 排在 `a10` 前面）跳首；YouTube 網址帶有播放清單（含 `list=`，包括 `RD…` 合輯）時，會在背景透過 `yt-dlp --flat-playlist` 取得清單並比對 `v=` 位置（取到之前按鈕先變灰，不卡住播放），換首會組成 `watch?v=<id>&list=<listId>` 讓重開仍可還原清單；單支影片或單一網址沒有上下首時按鈕變灰；抓不到清單時（例如私人清單：yt-dlp 沒有登入，看不到）按鈕也會變灰，滑鼠停在按鈕上會說明原因，可把清單改成「不公開」。播放位置超過 3 秒時按上一首會先回到這首開頭，3 秒內才跳前一首。一首自然播完（手動暫停不算）且仍有下一首時會自動接續播放，到最後一首就停下；換首會保留目前的倍速、音量、等化器、畫面開關與視窗大小，若播放失敗（`playFailed`、`resolveFailed`）則停在該首顯示錯誤，不會自動往下跳。
切換至電腦系統音訊頻譜（`system.ps1` 單一 PowerShell 程序）後，會記住上一個自己播放的檔案或網址（`lastSource`），再次點擊 📻 即可切回原來源播放（沒有先前來源時會清回等待拖入畫面）；進度條／細進度線、音量與播放速度鈕會隱藏；Windows 上若偵測到目前系統媒體工作階段，會於標題列顯示「歌名 — 演出者」，播放／暫停會控制該媒體，並依媒體支援度顯示上／下一首按鈕；無媒體工作階段時播放／暫停為凍結／恢復頻譜。開啟網址輸入框時，剪貼簿若有 HTTP(S) 網址會自動填入並選取，按 Enter 或點確定就能播放，也可以修改或清掉。介面語言與 ranchr、herdr-quota 共用；可使用 `tunr.language-auto`、`tunr.language-zh` 或 `tunr.language-en` 切換。

指令（`herdr-app do tunr.<指令>`，或在 `keys.json` 綁 `tunr.<指令>`）：`toggle`（播放／暫停）、`prev`（上一首：自己播的來源依 3 秒規則跳清單／資料夾，系統音訊模式控制瀏覽器）、`next`（下一首：自己播的來源跳清單／資料夾，系統音訊模式控制瀏覽器）、`volume-up`／`volume-down`（增減音量）、`speed`（切換下一檔播放速度：`1 → 1.25 → 1.5 → 2 → 0.75 → 1`）、`video`（開關畫面）、`eq`（開關縮小模式背景等化器）、`mode`（黑白／低彩）、`size`（依只聽聲音 / S / M / L 順序切換）、`smaller`（縮小；從 S 進只聽聲音）、`bigger`（放大；只聽聲音時開回畫面）、`opacity`（依 `100 → 75 → 50 → 25 → 10 → 5 → 100` 循環調整背景透明度）、`system`（來回切換系統音訊）、`system-on`（開系統音訊）、`system-off`（關系統音訊並切回上一個來源）、`close`。

## 設定

`~/.config/herdr-app/mods/tunr/config.json`，沒有也可以：

```json
{ "source": "system", "size": "S", "mode": "mono", "video": true, "eq": true, "volume": 80, "speed": 1, "opacity": 100, "debug": false }
```

- `source`：開啟時播什麼；填 `"system"` 為系統音訊，沒設就等你把檔案拖進來
- `lastSource`：切入系統音訊前記住的檔案或網址（供 📻 關掉時切回）
- `size`：`S`、`M`、`L`；`mode`：`mono`（黑白）、`low`（低彩度）；`video`：`false` 就是只聽聲音；`eq`：縮小模式是否顯示背景等化器（預設 `true`）；`speed`：播放速度（可選 `0.75`、`1`、`1.25`、`1.5`、`2`，預設 `1`，僅 tunr 自己播放的檔案／網址適用）；`opacity`：背景透明度百分比（`5`–`100`，預設 `100`）
- `debug`：`true` 時多一顆 FPS 按鈕，並每 2 秒把量到的數字寫到 `~/.config/herdr-app/data/tunr-stats.json`

在視窗裡調整音量、播放速度、黑白／低彩度、尺寸、開關畫面、縮小模式背景等化器（`eq`）、背景透明度，或是切換來源（拖入檔案、輸入網址、切換系統音訊與 `lastSource`），都會自動記在 `~/.config/herdr-app/data/tunr/settings.json`（不記錄播放位置秒數）；`config.json` 是手寫預設值（`install.mjs` 更新時也不會覆蓋，並會順手清掉舊版 `loopback.ps1` / `media.ps1`），想回到預設值只要刪掉 `settings.json` 即可。

## 運作方式

- 畫面在背景引擎（`tunr.mjs`）裡算好：ffmpeg 把影像縮成字元格轉成 ASCII，ffplay 放聲音，再用本機 TCP（`127.0.0.1`）一幀一幀送給視窗；視窗只負責畫和控制
- 引擎開在一個叫 `tunr-engine` 的背景終端；關掉視窗就一起關，啟動後若超過 60 秒無人連入，或斷線後沒人連線 15 秒，都會自己結束
- 聲音是主時鐘，畫面跟著聲音走，過期的幀直接丟掉，不會越播越慢
- 實測（Windows，每秒 24 幀，小視窗）：黑白每次重畫約 0.7 ms、不丟幀；低彩度每幀約 100 段文字、每秒約 23 幀

## 限制

- 系統音訊頻譜目前只支援 Windows（擷取 Windows 預設播放裝置的聲音），macOS 與 Linux 暫不支援
- 暫停、拉進度、換模式（或 ffmpeg 不支援 `azmq` 濾鏡時改音量）會重開背景程序，有 0.2–0.5 秒的空檔；支援 `azmq` 時改音量會直接即時套用，不中斷播放
- 不支援 Spotify、Podcast 搜尋；網站是否能播放取決於 yt-dlp 與來源限制

## 移除

關掉視窗，刪掉 `~/.config/herdr-app/mods/tunr/`。
